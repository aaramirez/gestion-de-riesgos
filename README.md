# Gestión de riesgos

Medir y controlar los riesgos de una institución financiera: riesgo de mercado con VaR y *expected shortfall*, crédito con PD, LGD, EAD y *scoring*, liquidez con LCR y NSFR, tasas y cambio en el balance, riesgo operacional, capital de Basilea y pruebas de estrés.

**Ver en línea:** https://aaramirez.github.io/gestion-de-riesgos/
